# Contribuer

Merci de votre intérêt pour la série « Une app par semaine ».

## Proposer une idée d'app

Les idées se proposent en commentaire de mes posts LinkedIn. Condition : l'app doit pouvoir tourner 100 % en local, sans serveur.

## Signaler un bug

Ouvrez une issue sur le dépôt de l'app avec : la version, le système, les étapes pour reproduire, le résultat attendu et le résultat obtenu. N'y mettez aucune donnée personnelle réelle.

## Signaler une faille de sécurité

Pas d'issue publique. Utilisez **Security > Report a vulnerability** sur le dépôt concerné.

## Proposer une modification (pull request)

- Une pull request = un changement.
- Les tests doivent passer, et toute nouvelle fonctionnalité a son test.
- Aucun secret, aucun appel réseau ajouté, aucune donnée réelle.
- Si vous avez utilisé une IA, dites-le dans la description : c'est l'esprit de la série.

En contribuant, vous acceptez que votre contribution soit publiée sous licence MIT.
